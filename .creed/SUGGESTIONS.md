# AgentCreed Suggestions

<!-- ↓↓↓ agentcreed ↓↓↓ -->

This file is used to collect Agentic AI suggestions about agent instructions discovered during development (ambiguities, discrepancies, contradictions, inefficiencies or possible improvements in `AGENTS.md`, `SECURITY.md`, skills, other instruction files and AgentCreed-managed text in any file). Tasks for the project codebase or documentation fixes out of the current task scope belong in `BACKLOG.md`.

This file holds pending suggestions only, as a numbered list. Resolved items are deleted, never marked as done. When deleting resolved, remaining items are renumbered.
