# nuxt-spec-cli

Lightweight CLI tool for [Nuxt Spec](https://nuxt-spec.netlify.app/).

```sh
npx nuxt-spec-cli setup
npx nuxt-spec-cli update
npx nuxt-spec-cli ci <github|gitlab>
```

Released in lockstep with `nuxt-spec` - each CLI version installs/updates the `nuxt-spec` version of the same number.

See the [documentation](https://nuxt-spec.netlify.app/1-2-installation.html) for details.
