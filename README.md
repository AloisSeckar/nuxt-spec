# Nuxt Spec

![Nuxt Spec](https://github.com/AloisSeckar/nuxt-spec/blob/main/public/nuxt-spec.png)

A _"testing done right"_ Nuxt base layer.

**Nuxt Spec** is a [Nuxt layer](https://nuxt.com/docs/4.x/getting-started/layers) focused on wiring-up pre-configured test features for Nuxt based on practical experience and latest trends. It allows nearly zero-config start while offering enough flexibility for advanced customization. Only a few changes are necessary to get started. And Nuxt Spec also ships with a CLI package for even more streamlined setup.

You are just one command away from having full and reliable test setup in your Nuxt project.
