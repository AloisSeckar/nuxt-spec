## Playground

Playground app is included in `/playground` folder. It is nothing but a Nuxt starter project from the official image. CLI scripts and latest features can be tested against it locally.

**WARNING**: The folder is Git tracked. **Be sure to ALWAYS revert changes and NEVER commit them!**
